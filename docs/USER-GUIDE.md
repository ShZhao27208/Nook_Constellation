# 隅星集 · Nook Constellation 使用说明

## 安装与启动

适用 Windows 10 2004 及以上、Windows 11，x64。安装包自带 .NET 运行环境。

1. 完整解压 `Nook-Constellation-1.0.3-win-x64.zip`。
2. 双击 `Install.cmd`；无需管理员权限。
3. 安装后自动启动；以后可使用桌面或开始菜单的“隅星集”快捷方式。

程序位于 `E:\NookConstellation`，任务数据库、设置和备份位于 `E:\NookConstellation\data`。窗口固定右下角，不支持拖动和自由调整大小。

## 记下任务

点击右下角 **＋**，输入标题后按 **Enter** 保存。默认紧急性、重要性各50，计划为今天，没有截止时间。

展开“时间、标签、评分与备注”可填写附加信息。开始时刻输入 `09:30`，截止输入 `2026-10-12 18:00`。日期可用日历选择；没有开始时刻表示在当天做。标签以逗号分隔。

标题和备注中选择文字后，出现加粗、斜体、颜色工具栏。支持 Ctrl+B/Ctrl+I。备注内 Enter 换行，Ctrl+Enter 保存。每秒保存编辑草稿；关闭编辑器后可恢复，选择“放弃草稿”清除。

## 找到接下来要做的事

- 横轴为紧急性，纵轴为重要性：`x=(紧急性−50)/10`，`y=(重要性−50)/10`。
- 默认50/50位于原点，归类为“重要不紧急”。实际位置由小圆点表示，标签可为避让而偏移；连线指向真实位置。
- 同一区域任务密集时显示数量，点击展开全部任务。
- 右上角放大按钮使窗口占屏幕四分之一；四象限占满内容区。点击任务查看或编辑细节，任务流显示任务卡片、时间、标签和备注。
- 左下角视图按钮切换四象限与任务流，设置中也可选择，并自动记住。
- 顶部左框搜索标题、备注和标签；中间框按标签筛选（多个标签任一匹配）；× 清除搜索与筛选。
- “今天”包含以前遗留的未完成任务；“全部”包含未来任务；下拉菜单可查看已完成与回收站。

## 更新任务

点击任务编辑。Shift+右键切换正在做状态，也可使用卡片的“开始做/暂停”。允许多个任务同时进行，金色光晕表示正在做。

“完成”隐藏任务；在“已完成”视图可恢复待做。“删除”后10秒内可撤销，回收站保留30天。重复任务修改或删除时，选择“仅这一次”或“这一次及以后”；修改未来待做任务时保留已完成历史。

支持每天、每周指定星期、每月指定日期；每月31日遇到短月按月末安排。未来实例提前生成60天，程序每天继续生成；重新启动补齐错过日期。

## 提醒

- 到计划开始时间提醒。
- 默认截止前15分钟提醒，设置可调整。
- 无开始时刻的当天任务默认9点汇总；9点后新增立即提醒。
- 退出或关机期间错过的提醒在下次运行汇总。
- 系统通知支持打开任务、10分钟后再提醒；设置中的“提醒记录”也提供这些操作。
- 已完成、删除的任务不再生成新提醒；正在做的任务保留截止提醒。

提醒检查间隔15秒。Windows 勿扰模式或通知权限可能影响弹出，提醒记录仍可查看。

## 窗口与托盘

关闭按钮隐藏窗口，提醒继续。托盘双击恢复；右键可显示、锁定/解锁、置顶、设置和退出。锁定后整个窗口鼠标穿透，只能通过托盘解锁，没有全局快捷键。

开机启动默认开启，设置可关闭；再次打开程序会恢复已有窗口，不创建多个实例。

## 备份与恢复

每天首次运行自动备份，持续运行时跨天也会备份。自动备份保留30份，手动备份不会被每日轮换删除。

设置提供：JSON完整导出、Markdown文字导出、导入合并、从备份恢复、立即备份、打开数据目录。JSON保留富文本、重复规则、提醒记录、设置和草稿；Markdown用于阅读归档，不用于完整恢复。

导入先预览，默认按ID合并、同ID保留修改时间较新的任务。恢复会替换当前数据与设置；两种操作前均自动备份当前数据。

## 卸载

通过 Windows“已安装的应用”卸载。先从托盘退出程序；卸载保留任务数据库与备份。
