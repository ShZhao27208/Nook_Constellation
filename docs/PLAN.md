# 隅星集（Nook Constellation）

## 目标与原则
快速记录、一眼判断优先级、及时更新状态。默认值减少填写；渐进展开高级字段；同一动作保持一致反馈；数据可恢复。

## 已确认需求
- Windows 独立桌面组件，单屏；固定右下角，不允许拖动或调整大小。小窗约 380×280 DIP；放大为屏幕宽高各一半。考虑任务栏边界与显示缩放。
- 全透明背景、白字带阴影、不透明边框；自选文字颜色优先。右上关闭与放大/还原、右下新增、设置按钮。
- 关闭隐藏到托盘；提醒持续运行；托盘可退出、显示、锁定/解锁、置顶。无全局快捷键；锁定整个窗口鼠标穿透，仅托盘解锁。重启默认解锁。
- 开机启动默认开启，可关闭；始终置顶可选；设置持久保存。
- 标题必填，备注、多个标签、计划日期/时刻、截止时间、紧急性/重要性。两种分数 0–100，默认 50。
- 新增聚焦标题，Enter 保存；附加字段展开填写；备注 Enter 换行，Ctrl+Enter 保存，有保存按钮。编辑保留未保存草稿。
- 标题与备注支持选区加粗、斜体、颜色，Ctrl+B/Ctrl+I，小工具栏。
- 状态为待做/正在做/已完成；支持多个正在做任务。Shift+右键切换高亮，详情提供等效按钮。完成隐藏，历史可恢复。
- 删除可在 10 秒内撤销，回收站保留 30 天。
- x=(紧急性−50)/10，y=(重要性−50)/10；坐标范围 −5～5；重要性≥50 为重要，紧急性>50 为紧急。默认原点归重要不紧急，通过分类标记说明。
- 默认四象限；默认显示今天及此前未完成任务，可切换全部（含未来）。小窗短标题、悬停详情；拥挤错开并保留位置锚点，过多聚合并可展开；放大显示完整详情，拥挤区域展开列表。
- 设置可选择任务流并记住；分组：正在做→已逾期→今天待做→未来；每任务仅出现一次，组内按计划开始时间，无时刻放组末。
- 未填计划时间归创建当天，无具体时刻；截止可为空。日期/时间精确到分钟。计划已过期与截止已过期分别标记。截止早于计划开始不能保存；允许录入已过期任务。
- 开始时通知一次，截止前默认15分钟提醒（可调）；无时刻当天任务9点汇总，9点后新增立即提醒一次。通知可打开任务/稍后10分钟；启动补偿错过提醒并汇总，避免重复；已完成/删除不提醒。
- 重复：每天、每周指定星期、每月指定日期；不存在的日期按月末；每次独立状态，错过保留；编辑/删除可选仅本次或本次及以后；启动补齐遗漏实例。
- 点击交互控件有短暂轻量粒子，可关闭，不拦截输入；穿透时不触发。正在做外框光晕保留文字颜色。
- 搜索标题/备注/标签，多标签按任一匹配，组合筛选、一键清除；历史可搜索。
- 本地 SQLite，无账号；立即持久保存。JSON完整导入导出（预览、按ID合并去重），Markdown导出；每天自动备份，保留30份，恢复前备份当前数据。

## 架构
.NET 8 WPF窗口；窗口行为与任务逻辑分离。SQLite事务持久化；提醒调度独立于窗口可见性；数据保存到当前Windows用户LocalAppData。时间按本地时区呈现，调度记录保留唯一标识。
